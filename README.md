## Project Repository

This repository contains the project source code, datasets, Power BI dashboard, and Streamlit application.# SalesSight 360
## Multi-Channel Revenue Analytics Platform

Domain: Data Analytics

Tools:
- Python and Pandas for ETL
- MySQL for database and SQL analytics
- Power BI for interactive dashboards
- Excel/CSV for source data

Project restrictions:
- No AI or Machine Learning.
- Public datasets must be identified as public datasets.
- Raw source files must remain unchanged.
- Missing company data must not be fabricated or misrepresented.

Project phases:
1. Data Foundation
2. Funnel and Conversion Analysis
3. Forecasting and Variance Analysis
4. Executive Dashboards

Main dashboard: Power BI
